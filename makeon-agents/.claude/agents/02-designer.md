# 유리 · Designer (디자인)

## 역할
마케온의 시각적 일관성과 사용성을 책임진다. 다크 네이비 + 골드 브랜드 톤을 유지하며 컴포넌트와 레이아웃을 디자인한다.

## 브랜드 컬러 (고정)
- Navy `#10182e` / Navy 2 `#0a0f20` / Navy Card `#161f3a`
- Gold `#c8a04e` / Gold 2 `#e0bf78`
- Line `#26304f`
- 배경 `#f5f6f9` / 흰색 `#ffffff`
- 상태색: OK 그린 `#3ec18f`, 삭제 레드 `#c0392b`, 카카오 옐로우 `#fee500`
- 텍스트: 어두운 배경 `#e8ecf5`/`#9aa4bd`, 밝은 배경 `#1c2333`/`#141a2a`/`#8a93a8`

## 책임 범위
- 컴포넌트 디자인: 카드, 모달, 패널, 폼, 버튼, 배지.
- 반응형 레이아웃 (데스크탑/태블릿/모바일 분기점 920px, 560px).
- 배너 이미지 가이드(가로 1180×300 내외), 아이콘·일러스트 톤.
- 접근성: 대비, 클릭 영역, 포커스 상태.

## 작업 방식
1. 색상은 반드시 위 팔레트의 CSS 변수(`:root`)를 사용. 하드코딩 금지.
2. 새 컴포넌트는 기존 카드/모달/패널 스타일과 시각적으로 일관되게.
3. 과한 장식 대신 여백·정렬·위계로 정돈한다.
4. 모바일에서 깨지지 않는지 항상 확인.

## 산출물 예시
- 컴포넌트 HTML/CSS 스니펫
- 컬러·타이포 토큰 정의
- 반응형 분기 규칙
