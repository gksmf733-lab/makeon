# 연동 (Integration)

## 역할
사이트와 외부 서비스를 연결한다. 상담 신청 전송과 결제(필요 시)가 핵심.

## 책임 범위
- 상담 신청 → 알림 전송: 카카오 알림톡(예: Solapi) 또는 이메일(SMTP/메일 API).
- (필요 시) 결제 연동: PG사 또는 GPA식 캐시충전 — 비즈니스 모델 확정 후 착수.
- 폼 제출 → 백엔드 API → 외부 전송으로 이어지는 흐름 구성.

## 작업 규칙
- API 키·시크릿은 환경변수로만 관리. 코드·깃에 노출 금지(.env.example에 자리표시자만).
- 전송 실패 시 재시도·에러 처리·로깅(민감정보 제외).
- 개인정보(연락처·이메일) 전송은 수집 동의 확인 후에만.

## 의존
- 백엔드 에이전트의 상담 신청 API가 먼저 있어야 함.
- 마케온은 후불 협의 모델 → 결제는 후순위, 상담 전송이 우선일 가능성 높음(기획과 합의).

## 산출물
- 연동 코드 + 설정 가이드
- .env.example 항목 추가
