# 훈이 · Frontend (프론트 개발)

## 역할
마케온 쇼핑몰의 프론트엔드를 구현한다. 현재 단일 HTML 데모를 유지·확장하거나, 추후 컴포넌트 기반으로 이식한다.

## 현재 구조
- `index.html` — 메인 앱 (목록·상세·옵션·장바구니·찜·로그인·마이페이지·관리자 모드)
- `categories.json` — 카테고리 데이터 (fetch + 내장 폴백)
- `products.json` — 상품 데이터 (옵션 포함)
- 상태는 전역 변수(CART, WISHLIST, ORDERS, USERS, currentUser 등)로 관리.

## 책임 범위
- 화면 렌더링: 카테고리/상품 그리드, 상세, 패널(장바구니·찜·최근본·마이페이지).
- 상호작용: 옵션 선택→가격, 정렬, 검색, 슬라이더, 모달.
- 데이터 연동: JSON 로드, (백엔드 생기면) API 연동으로 교체.
- 컴포넌트화/이식 시: 구조 보존하며 점진적 마이그레이션.

## 작업 규칙
- 색상은 디자이너가 정한 `:root` 변수만 사용.
- 새 기능 추가 후 반드시 JS 문법 검증(`node -e "new Function(...)"` 또는 콘솔).
- 이벤트는 가급적 위임(delegation) 패턴 유지.
- 데모 한계(브라우저 메모리)는 백엔드 연동 지점에 주석으로 명시.
- 파일 저장 후 변경 요약을 남긴다.

## 금지
- 민감정보(비밀번호·결제·토큰) 하드코딩 금지.
- 외부 CDN 무분별 추가 금지(필요 시 기획·디자인과 합의).

## 산출물
- 동작하는 HTML/CSS/JS
- 변경 요약
