# MAAKEON 마케온 홈페이지 — 멀티 에이전트 작업 가이드

이 프로젝트는 Claude Code(터미널)에서 여러 전문 에이전트로 나눠 작업하기 위한 구성이다.
에이전트 정의는 `.claude/agents/` 에 있다.

## 프로젝트 개요
소상공인 대상 온라인 마케팅 서비스 쇼핑몰.
- 현재: 프론트엔드 데모(`index.html` + `categories.json` + `products.json`).
- 데모 한계: 로그인·찜·장바구니·마이페이지가 브라우저 메모리 기반(새로고침 시 초기화).
- 다음 목표: 백엔드 연동으로 실제 운영 사이트화.

## 브랜드 컬러 (전 에이전트 공통, 고정)
- Navy `#10182e` · Navy2 `#0a0f20` · NavyCard `#161f3a`
- Gold `#c8a04e` · Gold2 `#e0bf78` · Line `#26304f`
- 배경 `#f5f6f9` · 흰색 `#ffffff`
- 상태: OK `#3ec18f` · 삭제 `#c0392b` · 카카오 `#fee500`

## 에이전트 구성
| # | 에이전트 | 호출 키 | 역할 |
|---|---|---|---|
| 01 | 철수 Planner | `planner` | 기획·명세·데이터 설계·우선순위 |
| 02 | 유리 Designer | `designer` | UI·컴포넌트·반응형·배너 |
| 03 | 훈이 Frontend | `frontend` | 화면·상호작용·상태관리 |
| 04 | Backend | `backend` | 회원·주문·찜·파일·API·DB |
| 05 | 짱구·맹구 QA | `qa` | 기능 점검·호환성·회귀 테스트 |
| 06 | Content | `content` | 카피·상품설명·후기·약관 |
| 07 | Integration | `integration` | 알림톡·이메일·결제 연동 |
| 08 | DevOps | `devops` | 깃·배포·도메인·환경변수 |

## 표준 작업 흐름
1. **planner** — 요구사항을 명세·데이터 스키마·작업 분해로 정리.
2. **designer** — 필요한 화면/컴포넌트 디자인.
3. **frontend / backend** — 병렬 구현 (인터페이스는 planner가 맞춰둠).
4. **content / integration** — 문안·외부 연동 채움.
5. **qa** — 통합 점검·회귀 테스트.
6. **devops** — 배포(인증 작업은 사용자가 직접).

## 현재 우선순위(권장)
1. backend: 회원 인증 + 주문/상담 영구 저장
2. integration: 상담 신청 → 카카오 알림톡/이메일 전송
3. content: 약관·개인정보처리방침·사업자 정보 실제 문안
4. (선택) 결제: 비즈니스 모델 확정 후 — 마케온은 후불 협의 모델이라 상담 우선

## 공통 규칙
- 색상은 `:root` CSS 변수만 사용(하드코딩 금지).
- 자격증명·시크릿(비밀번호·토큰·API 키)은 코드/깃에 절대 노출하지 않는다. `.env` + `.gitignore`.
- 인증이 필요한 작업(깃 푸시, 계정 로그인, 배포 인증)은 사용자가 직접 수행 — 에이전트는 절차만 안내.
- 타사 콘텐츠를 베끼지 않는다. 구조 참고는 가능하나 텍스트·디자인은 마케온 오리지널.
- 코드 변경 후 JS 문법 검증 + 변경 요약.

## 사용 예 (Claude Code)
```
# 기획부터
> planner 에이전트로 회원 주문 내역 영구 저장 기능을 설계해줘

# 구현
> backend 에이전트로 위 설계대로 회원 인증 API를 만들어줘
> frontend 에이전트로 로그인 폼을 실제 API에 연결해줘

# 점검·배포
> qa 에이전트로 로그인 흐름 전체를 점검해줘
> devops 에이전트로 배포 절차를 안내해줘
```
