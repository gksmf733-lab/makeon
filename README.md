# MAAKEON 마케온 온라인 마케팅 쇼핑몰

소상공인 대상 온라인 마케팅 서비스 쇼핑몰 (프론트엔드 데모).

## 구성
- `index.html` — 메인 애플리케이션 (목록·상세·옵션·장바구니·찜·로그인·마이페이지·관리자 모드)
- `categories.json` — 카테고리 구조 데이터
- `products.json` — 상품 데이터

## 로컬 실행
정적 파일이라 별도 빌드 없이 브라우저로 `index.html`을 열면 됩니다.
(외부 JSON 로드를 위해 로컬 서버 권장: `npx serve` 또는 `python3 -m http.server`)

## 배포
정적 사이트로 어디에나 배포 가능 (Vercel / Netlify / GitHub Pages 등).
Vercel 배포 시 빌드 설정 없이 루트의 `index.html`이 그대로 서빙됩니다.

## 참고
- 로그인·찜·장바구니·마이페이지는 현재 브라우저 메모리 기반 데모입니다(새로고침 시 초기화).
- 실제 운영을 위해서는 백엔드(회원·주문·결제·DB) 연동이 필요합니다.
